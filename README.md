# Danroylex Mboya — Portfolio

A senior backend engineer's portfolio site. Built with Next.js 16 (App Router), TypeScript, Tailwind CSS v4, Framer Motion, and MDX — designed to read like Stripe/Linear/Vercel rather than a generic developer template.

Live sections: animated hero, impact metrics, four in-depth case studies, four animated architecture diagrams, an MDX-powered writing section with search, an interactive resume with PDF download, and a contact form wired to Resend. A command palette (`⌘K` / `Ctrl+K`) lets visitors jump anywhere instantly.

## Tech stack

- **Framework:** Next.js 16 (App Router, Turbopack)
- **Language:** TypeScript (strict mode)
- **Styling:** Tailwind CSS v4, custom design tokens (dark-first, light mode via `next-themes`)
- **Animation:** Framer Motion (counters, code reveal) + native SVG `<animate>` for diagram flow
- **Content:** MDX via `next-mdx-remote`, frontmatter via `gray-matter`, reading time via `reading-time`
- **Command palette:** `cmdk`
- **Email:** Resend (server action, graceful fallback if unconfigured)
- **Icons:** `lucide-react` + two small custom SVGs (GitHub/LinkedIn, since brand icons aren't in lucide-react 1.x)

## Getting started

```bash
npm install
npm run dev
```

Visit `http://localhost:3000`.

### Environment variables

Copy `.env.example` to `.env.local` and fill in:

```
RESEND_API_KEY=          # from resend.com — required for the contact form to actually send email
NEXT_PUBLIC_SITE_URL=    # your production domain, used in metadata/sitemap/OG tags
```

Without `RESEND_API_KEY`, the contact form still renders and validates, but shows a friendly message asking visitors to email you directly instead of silently failing.

## Content management

Everything content-related lives in plain TypeScript or MDX — no CMS, no database.

- **Projects / case studies:** `src/data/projects.ts`. Each entry drives both the homepage card and the full `/work/[slug]` case study page (problem, architecture diagram, challenges, solutions, results).
- **Skills:** `src/data/skills.ts` — categorized lists, no skill bars.
- **Career timeline:** `src/data/timeline.ts` — feeds the `/resume` page.
- **Availability / current focus / contact info:** `src/data/site.ts`. Flip `availableForWork: false` to switch the whole site's status badges to "not currently available."
- **Blog posts:** drop a new `.mdx` file into `src/content/` with this frontmatter:

  ```md
  ---
  title: "Post Title"
  description: "One-sentence summary."
  date: "2026-03-01"
  tags: ["go", "postgresql"]
  ---

  Your content here, in Markdown.
  ```

  It will automatically appear in `/writing`, get a reading-time estimate, and become searchable client-side.
- **Architecture diagrams:** `src/components/diagrams/`. Each diagram is a small SVG-flow component built on the shared `FlowDiagram` primitive — edit node/edge coordinates directly, or add a new diagram and register it in `src/components/diagrams/index.tsx`.
- **Resume PDF:** generated by `scripts/generate_resume.py` (Python + reportlab) into `public/resume.pdf`. Edit the script and re-run `python3 scripts/generate_resume.py` after updating your experience or projects, so the downloadable PDF stays in sync with the site.

## Deploying to Vercel

1. Push this repository to GitHub (see below).
2. Go to [vercel.com/new](https://vercel.com/new) and import the repo.
3. Vercel auto-detects Next.js — no build settings to change.
4. Add environment variables in the Vercel project settings (`RESEND_API_KEY`, `NEXT_PUBLIC_SITE_URL`).
5. Deploy. Subsequent pushes to `main` auto-deploy.

## Project structure

```
src/
  app/             Next.js App Router routes
  components/
    ui/            Small reusable primitives (Button, Badge, Card, etc.)
    sections/      Homepage and page-level sections
    diagrams/      Animated SVG architecture diagrams
  content/         MDX blog posts
  lib/             Utilities — MDX loader, metadata builder, contact server action
  data/            Typed constants — projects, skills, timeline, site config
scripts/           Python script that generates public/resume.pdf
```

## Notes

- Lighthouse-friendly by default: no client-side font loading (system font stack), static generation for every route, minimal JS on first paint.
- Reduced-motion is respected globally (`prefers-reduced-motion`).
- The contact form uses React 19's `useActionState` with a server action — no client-side fetch boilerplate.
